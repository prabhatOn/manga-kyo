# 狂 MANGA-KYO (万華狂) — The Retro-Modern Editorial Manga Sanctuary

> **God-Level Japanese Editorial Manga Platform** featuring authentic Shonen & Seinen masterworks, verified English & Hindi chapters, dual **和 Japanese Color** & **墨 Noir (B&W)** themes, Web Audio tactile sound synthesis, and full MangaDex API v5 integration.

---

## ✦ Key Highlights & Features

- **🏯 Dual Aesthetic Themes**:
  - **和 JAPANESE COLOR**: Deep Sumi lacquer ink background (`#07060a`), radiant vermilion red (`#e60012`), Kin gold accents, and warm washi paper tones.
  - **墨 NOIR (Monochrome)**: High-contrast silver-gelatin black-and-white, authentic halftone screentone dots, and ink-wash atmosphere.
- **📖 Next-Gen Pro Manga Reader**:
  - 4 reading modes: **Webtoon Infinite Vertical Scroll**, **Japanese RTL (Right-to-Left)**, **Western LTR**, and **Double Spread**.
  - Integrated **Noir Filter Toggle** (instantly convert any manga page into crisp high-contrast B&W).
  - Reader Themes: OLED True Black, Vintage Tankōbon Paper, Warm Sepia, and Pure White.
  - Image preloading engine and keyboard shortcuts (`← / →`, `Space`, `F`, `Esc`).
- **🇮🇳 Curated Hindi & English Archives**:
  - Verified official Hindi translated chapters (One Punch-Man, SPY×FAMILY, Burning Kabaddi, One Piece).
  - High-res covers and 100% active verified chapter pages via MangaDex API v5.
- **🔊 Web Audio API Sound Engine**:
  - Synthesized tactical SFX without external audio asset dependencies:
    - Dramatic Anime *"DON!!"* (ドン!!)
    - Katana Slash (*Zan*)
    - Tactile mechanical clicks and paper rustles.
- **✨ Retro-Modern Full-Width Navbar**:
  - Edge-to-edge glassmorphic design (`backdrop-blur-2xl bg-[#07060a]/90`).
  - Integrated `/` quick search, language filter pills (`ALL` / `EN` / `हिन्दी`), and live bookmark Vault.

---

## 🛠 Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8
- **Styling**: Tailwind CSS v4 + Custom Screentone & Ink Design System
- **Animation**: GSAP (GreenSock Animation Platform)
- **Icons**: Lucide React
- **Audio**: Native Web Audio API Synthesizer
- **Data Source**: MangaDex REST API v5 (`/manga`, `/chapter`, `/at-home/server`)

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/prabhatOn/manga-kyo.git

# Navigate into the project
cd manga-kyo

# Install dependencies
npm install

# Start the development server
npm run dev

# Build for production
npm run build
```
